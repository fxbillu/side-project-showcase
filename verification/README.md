## 离线复算

可克隆公开展示仓库，然后在仓库根目录运行：

```bash
python3 verification/verify.py
```

也可[下载独立材料包](https://fxbillu.github.io/side-project-showcase/verification.zip)，解压后运行同一命令。只需要Python 3标准库，不需要登录、私有源码或数据库。预期输出为 `status: PASS`、`arithmeticExamples: 3`。

[复算脚本](verify.py)首先核对[文件哈希清单](evidence-manifest.json)，再用Decimal逐行计算。哈希用于识别文件内容，不是数字签名。公开摘录是维护者提供的材料，不构成第三方签收。
